# Agile Internal Marks Tracker - R23

A simple internal marks tracker built for my college to calculate R23 internals correctly.

**Problem:** College app was showing wrong 50/50 marks in Agile Methodologies subject. Students confused about actual internal marks.

**Solution:** This tracker calculates R23 internals:
- Descriptive: 10 marks
- Assignment: 5 marks
- Online Quiz: 15 marks
Total: 30 Internal Marks

**Tech Used:** Simple logic, works offline, no database needed.

**Why I built it:** Nobody asked me. I built it because my friends were worried about their internals.

**How to use:**
1. Enter Descriptive marks
2. Enter Assignment marks
3. Enter Quiz marks
4. Get correct internal total
